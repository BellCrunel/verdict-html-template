# Verdict - Law Firm HTML Template

Verdict is a responsive HTML template for law firms, attorneys and legal consultants. Built with Bootstrap 5, it comes with 10 ready pages, a testimonials slider, animated counters and a contact form layout.

## Features

- 10 HTML pages
- Bootstrap 5, fully responsive
- AOS scroll animations and Swiper slider
- Bootstrap Icons
- Self-hosted Google Fonts (DM Sans, Playfair Display)
- Contact form with success message (connect to your own mailer)
- Clean, commented code
- Documentation included

## Pages

index.html, about.html, practice-areas.html, practice-single.html, attorneys.html, attorney-single.html, blog.html, blog-single.html, contact.html, 404.html

## Live demo

This repository hosts the live demo. The template package (with documentation) is available on Codester: https://www.codester.com/RelictTheme/

Demo images are not included. The download contains placeholders with the image size written on them. Replace them with your own photos using the same file names.
